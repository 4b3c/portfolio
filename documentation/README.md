# Zipper Documentation

This folder contains focused docs for core parts of the codebase.

## Files

- `ARCHITECTURE.md`: Main runtime architecture and execution flow.
- `SESSION_STORAGE.md`: Session layout, traces, conversations, state, and versions.
- `CONVERSATION_AND_STREAMING.md`: Agent conversation loops, tool calls, compaction, and streaming behavior.
- `MODULES_REFERENCE.md`: Built-in modules and their responsibilities.
- `PROMPTS_AND_ROUTING.md`: System prompts, difficulty classification, and model routing.
- `FAILURE_AND_RECOVERY.md`: Failure handling, restart behavior, and pause flow for rate limits.
- `MODULE_BUILDING.md`: Steps and patterns for creating a new module.

## Recommended Reading Order

1. `ARCHITECTURE.md`
2. `SESSION_STORAGE.md`
3. `MODULES_REFERENCE.md`
4. `CONVERSATION_AND_STREAMING.md`
5. `PROMPTS_AND_ROUTING.md`
6. `FAILURE_AND_RECOVERY.md`
