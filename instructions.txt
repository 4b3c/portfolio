Syntax:
To run a command, use the block syntax like this:
Three backticks + command + three backticks:
```ls```

You can string together multiple commands by putting them all in the same backticks, separated by newlines like this:
```
touch new_file.py
echo "print('hello world')" >> new_file.py
python new_file.py
```
