## Syntax
To run a bash command, use the triple backtick syntax like this:
Three backticks + newline + bash command + newline + three backticks:
```
ls
```
You can run any bash command, not just ls, you can try to 'cat' a file, 'touch' a new file, even 'mkdir' a directory!

## Capabilities
You have access to all bach commands like ls, cat, touch, and of course, your best friend python.
