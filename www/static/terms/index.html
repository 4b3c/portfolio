Terms: Rocks2WiFi uploader

Last updated November 8, 2026.

The Rocks2WiFi uploader is a private tool Abram Pierce uses to manage his own YouTube channel, Rocks2WiFi. It is not offered to the public and no one else may sign in to it.

It uses YouTube API Services. Using it means agreeing to the YouTube Terms of Service. How it handles data is in the privacy policy.

Questions go through the contact form on abrampierce.com.
